DOSE：基于 UK Biobank 的数据驱动卒中膳食评分构建及其与缺血性卒中风险的前瞻性研究

基于 UK Biobank 构建并验证一种数据驱动的卒中膳食评分 DOSE，是一种面向缺血性卒中预防、在传统健康饮食框架基础上进一步优化和细化的数据驱动膳食结构评分。
1、在通过 207 种食物和 39 个食物组的 food-wide association study、RCS
2、机器学习辅助筛选，确定了 7 个候选食物组，
3、整合为 5-component intake-based DOSE，与传统饮食评分比较分析；km和10年风险分析；敏感性分析；亚组分析；遗传风险分层分析；outcome-wide 分析DOSE与其他结局的关联
